# Meter feature parity

This table tracks the **application's** meter features after Phase 4. `Supported` means editor stills and exported MP4 frames use real Prism analysis and drawing. It does not claim pixel-for-pixel equivalence with MiniMeters. Prism is pinned to `49721802252b115d169e353c98b27408daa5e2b7`. MiniMeters features below are drawn from its [official feature list](https://minimeters.app/); Prism capabilities are checked against the pinned source paths named in the evidence column. Phase 4 left meter controls unchanged and rerendered all eight categories together; see the [Phase 4 report](phase-4-report.md).

| Feature or mode | Status | Evidence and scope |
| --- | --- | --- |
| Spectrum line, mid channel | Supported | Prism `native/src/spectrum.cpp` and `src/renderer/visualizers/SpectrumAnalyzer.ts`; 440 Hz and 1 kHz fixture peaks, editor stills, and MP4 frames in [Phase 3.1 report](phase-3-1-report.md). |
| Spectrum side channel line | Supported | Optional side line uses Prism `getSideMagnitudes`; anti-phase fixture has silent mid and strong side. Separate L/R display is not exposed yet. |
| Spectrum FFT sizes 1024, 2048, 4096, 8192 | Supported | Per-layer settings in `phase2/project.cjs`, native prepasses in `phase3/spectrum.cjs`; two unlike instances verified. MiniMeters also lists 16384, which is not exposed here. |
| Spectrum logarithmic, Mel, linear frequency scales | Supported | Prism `types/frequencyScale.ts` and `SpectrumAnalyzer.ts`; UI selection saved and restored. Display mapping is Prism's implementation. |
| Spectrum frequency/dB ranges | Supported | Prism Canvas options; per-layer controls, validation, and history checks. |
| Spectrum smoothing response versus live Prism | Different behavior | Uses Prism's native smoothing math and independent per-layer values, updated once per 30 FPS video frame. Live Prism can receive chunks at a different cadence, so its transient response may differ. |
| Spectrum left/right mode | Not yet implemented | Current analysis captures Prism mid and side magnitudes. MiniMeters lists L/R and M/S channel modes; L/R needs a separate rendering/data path. |
| Spectrum 16384 FFT, color bars, combined mode, frequency readout | Not yet implemented | MiniMeters lists these on its official feature page. Current UI exposes line mode and FFT sizes through 8192. |
| Spectrum tilt, heatmap, reference curve | Not yet implemented | Prism `SpectrumAnalyzer.ts` has tilt, heatmap, and reference options; they are not wired into this application's project schema or export. |
| Vectorscope five stereo projections and zoom | Supported | Prism `native/src/vectorscope.cpp`, `src/renderer/visualizers/Vectorscope.ts`, and `vectorscopeGrids.ts` draw Lissajous, polar unipolar/bipolar, and linear unipolar/bipolar. Independent layer mode, −12 to +24 dB zoom, trace color, and grid controls are saved. Five distinct stills, two unlike instances, and sampled MP4 frames are verified in the [Phase 3.8 report](phase-3-8-report.md). |
| Vectorscope native low/mid/high traces and colors | Supported | Prism's native `pushMultibandSamples`/`getMultibandPoints` and its multiband Canvas path are fed in preview and export. A 100 Hz tone favored low; a 5 kHz tone favored high. Three colors are saved per layer. |
| Vectorscope overall and low/mid/high correlation | Supported | Optional signed indicators use normalized L/R cross-correlation over the latest 1024 Prism native points, including three split-band pairs. Silence and one-sided audio display 0; in-phase and anti-phase fixtures display +1 and −1. This window differs from Prism's native VU correlation integration. |
| Vectorscope MiniMeters RGB and specialized scaled variants | Different behavior | The pinned Prism painter offers five projections and three-band colors, but not MiniMeters' RGB and specialized scaled modes as described on its official feature list. |
| Spectrogram FFT size and frequency scale | Supported | Prism `native/src/spectrogram.cpp` and `Spectrogram.ts`; per-layer 1024/2048/4096/8192 FFT and log/Mel/linear scale controls. Two unlike instances, native rows, editor stills, and MP4 frames verified in [Phase 3.3 report](phase-3-3-report.md). |
| Spectrogram horizontal/vertical scrolling history | Supported | Prism's Canvas waterfall painter scrolls native columns along the selected time axis. A 440 Hz to 1 kHz transition retained both frequency rows in history; backward seek and resize replay matched, including 1080p export. |
| Spectrogram color, clarity, range, speed, contrast, and tilt | Supported | Per-layer heat/mono scheme, Prism clarity mode, frequency/dB ranges, scroll speed, contrast, tilt, and grid controls are validated and saved. Heat uses Prism's color LUT; mono uses the layer trace color. |
| Spectrogram DAW timeline ruler | Different behavior | Prism's timeline labels require a `daw-bridge` backend; file-based offline composition has no DAW transport, so the frequency grid is shown without that ruler. |
| Oscilloscope sample wave and pitch trigger | Supported | Prism `native/src/oscilloscope.cpp` and `src/renderer/visualizers/Oscilloscope.ts`; Phase 3.2 native frequency and consecutive-frame trigger checks, editor stills, and MP4 frames in [Phase 3.2 report](phase-3-2-report.md). |
| Oscilloscope free-running, underfill, and grid controls | Supported | Per-layer project settings use the same Prism Canvas painter; pitch-locked and free-running instances were tested together and independently. |
| Oscilloscope channel routing | Different behavior | Prism's oscilloscope consumes the left channel from `AudioRouter.ts`; this application follows it. The user cannot select right, mid, or side for this meter. |
| Oscilloscope time-window/trigger adjustment | Not yet implemented | Prism fixes the display window through `getNormalizedOscilloscopeDisplaySamples`; the application exposes pitch lock, not an adjustable window or trigger level. |
| Scrolling waveform mono and stereo history | Supported | Prism `native/src/waveform.cpp` peak summaries and `src/renderer/visualizers/Waveform.ts` Canvas painter; independently configured mono and stereo layers, editor stills, and 720p/1080p MP4 in [Phase 3.4 report](phase-3-4-report.md). Mono follows Prism's left-channel routing. |
| Waveform peaks, speed 1–8, and multiband colors | Supported | Native min/max and low/mid/high RMS columns drive Prism's painter. A pulse reached 0.977 peak; 100 Hz favored low red and 5 kHz high blue; speeds 1 and 4 produced 4 and 17 columns in a sampled frame. Per-layer colors and speed save/reopen. |
| Waveform L/R/M/S selection and loop | Different behavior | The app follows Prism's waveform `mono` left-channel and `stereo` L/R modes. MiniMeters lists L/R/M/S channel selection and loop; selectable M/S and loop are not exposed by pinned Prism's waveform painter. |
| Waveform DAW timeline ruler | Different behavior | Prism's timeline depends on a DAW transport. This file-based offline editor retains its waveform grid without DAW bar/beat labels. |
| Waterfall spectrum history and frequency placement | Supported | Prism `native/src/waterfall.cpp`, `src/renderer/visualizers/Waterfall.ts`, and `waterfallPlot.ts` supply the native 60 Hz history and Canvas ridges. Silence, 440 Hz stereo phase variants, 1 kHz transition, editor stills, and 720p/1080p MP4 were checked in the [Phase 3.7 report](phase-3-7-report.md). This is a Prism category rather than a distinct MiniMeters module in its current official feature list. |
| Waterfall FFT, frequency scale/range, history, density, smoothing, tilt, theme/heat color, guides | Supported | Independently configured layers support Prism's 1024–16384 FFT, log/Mel/linear scale, audible/extended frequency range, 1–30 s history, sparse/balanced/dense ridges, native smoothing/tilt, and painter colors/guides. Two unlike instances retained independent history through preview and export. |
| Waterfall live capture-gap sequence reset | Different behavior | Pinned Prism's live painter can reset its history when incoming capture sequence numbers skip. Offline decoded files are continuous, so the editor/export pipeline has no live capture sequence or gap reset. |
| Momentary, short-term, and integrated LUFS | Supported | Prism `native/src/lufsmeter.cpp` provides K-weighted 400 ms momentary, 3 s short-term, and gated integrated readings. Prism `LUFSMeter.ts` draws selectable per-layer readouts. Native values agreed with FFmpeg EBU R128 on the [Phase 3.6 fixture](phase-3-6-report.md). |
| Oversampled true peak and peak hold | Supported | Prism native FIR reconstruction provides the cumulative true-peak maximum. A frame-clocked port of Prism's FIR and 750 ms hold/18 dB/s decay drives deterministic per-channel display peaks. The port's cumulative maximum agreed with native output within 0.05 dB at sampled frames. |
| Fast/slow RMS windows and configurable loudness target | Not yet implemented | Prism's painter shows L/R fast bars and a fixed −14 LUFS guide. Separate selectable fast/slow RMS windows and an adjustable target are not exposed. |
| VU ballistics, correlation, and calibration | Supported | Prism `native/src/vumeter.cpp` provides 300 ms RMS integration and full-band stereo correlation, which Prism `VUMeter.ts` already draws; Prism `vuMeterBallistics.ts` supplies deterministic peak hold/decay for offline frame time. The 0 VU reference is configurable from −30 to 0 dBFS per layer. See [Phase 3.5 report](phase-3-5-report.md). |
| VU bars, needles, and channel display | Supported | Prism `VUMeter.ts` paints horizontal/vertical stereo bars and stereo/combined needles. Two unlike instances, all four visual styles, editor stills, and 720p/1080p MP4 were verified. Bar channels are fixed to L/R; combined needle uses a stereo RMS dB average. |
| VU selectable L/R/M/S input routing | Not yet implemented | MiniMeters lists channel routing; this app supplies Prism's L/R VU input and does not expose selectable M/S routing. |

`Different behavior` and `Not feasible` remain available statuses for future rows when a tested feature warrants them. Features listed as not yet implemented are roadmap items, not claims that Prism cannot provide them.
