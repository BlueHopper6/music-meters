# Phase 4: music-video composition

## Result and implementation

**PASS for the Phase 4 composition gate.** This branch started from clean `main` and freshly fetched `origin/main`, both at `b3fed2abc9ff73c5daab58bd7801c3f195bc2e3b` (merged PR #11). Prism remains pinned to `49721802252b115d169e353c98b27408daa5e2b7`; Astrofox remains pinned to `ef3312505eb2830f34440da0196fa1ec545be659`. Neither upstream checkout was edited.

Version 2 projects add ordered image and text layers and solid, gradient, or image backgrounds. The editor lets users position and resize them alongside any Prism meter; set image crop or fit, opacity, rotation, shadow, and local artwork; and set text content, font, size, weight, alignment, color, rotation, and shadow. The project title is metadata in version 2 and is no longer painted separately behind a title text layer. Version 1 projects retain their fixed title/subtitle/timestamp painter and continue to open, save, and export. Adding a graphic layer or changing background style upgrades a version 1 project and converts its title to a text layer.

`phase2/composition.ts` remains the common painter for editor stills and MP4 frames, including the original eight Prism meters. It composites layers in their saved order with Canvas alpha; text is rasterized at the output resolution. Electron renderer isolation, sandboxing, and narrow IPC remain enabled. The native image picker accepts PNG, JPEG, and WebP. Each file is checked for extension, signature, size, and local path; project saves copy artwork into a sibling `<name>.assets` folder under content-hash filenames. Stored artwork references are restricted to that folder. The renderer receives validated image bytes as data URLs through IPC; it has no Node file access. Missing or undecodable images produce an editor error and block export. FFmpeg still receives the source audio separately for AAC encoding, with no mastering or effects.

## Commands and measured behavior

Commands run: `node phase2/build.cjs`; strict `tsc --noEmit` for composition/editor/export with pinned Prism declarations; `node --test phase4/test/assets.test.cjs phase2/test/project.test.cjs phase1/test/pcm-reader.test.cjs phase3/test/vectorscope-correlation.test.cjs`; `python phase4/test/make-art.py`; `node phase4/test/run-gate.cjs`; `node phase4/test/run-legacy.cjs <gate-dir>`; `node phase2/export.cjs` for 720p repeat, 1080p, image background, all-eight regression, and cancellation; `python phase4/test/compare-frame.py` for three samples; `python phase4/test/compare-repeat.py`; `python phase3/test/compare-all-meters-frame.py` for three samples; and `python phase3/test/verify-export.py` for the two gate outputs and all-eight regression.

For the same six-layer gradient project, the measured local 720p repeat export took **12.27 s** (10.44 s rendering/PNG transfer, 0.47 s encoder backpressure, 212,844,544-byte peak Electron main-process RSS). The 1080p export took **23.87 s** (21.35 s rendering/PNG transfer, 0.95 s encoder backpressure, 209,797,120-byte peak main RSS). RSS excludes the renderer and FFmpeg. These are single local observations, not throughput guarantees. Text and meter strokes were rasterized at their respective output sizes; the editor stage uses 1280×720 project coordinates.

## Limits

Text is single-line and clipped to its layer bounds; there is no wrapping, outline, or glow control. Shadow blur is available up to 40 project pixels. The font menu offers five common system families; exact glyph metrics can differ on a machine with different installed fonts. Each image is limited to 8 MB and all referenced artwork together to 24 MB. Keep the generated `.assets` folder beside its project JSON. An old version 1 project upgraded to version 2 gets its title as a text layer, but its previous decorative subtitle and timestamp are not migrated. Long-song preview still reprocesses from the beginning. These Phase 4 tests did not exercise a native file-picker click or an audio-player audition; they used generated assets, automated picker injection, full-file decode, audio comparison, and manually viewed sampled frames. Exported AAC is lossy.
