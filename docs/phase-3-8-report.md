# Phase 3.8: Prism vectorscope modes and correlation

## Result and source

**PASS.** Work began from clean `main` at `602491042814bb4d508775aed1ee1213771dd053` (merged Phase 3.7 PR #10) on `feature/phase-3-vectorscope-modes`. Prism remains pinned to `49721802252b115d169e353c98b27408daa5e2b7`; Astrofox remains pinned to `ef3312505eb2830f34440da0196fa1ec545be659`. No upstream checkout source was edited.

Phase 0/2 supplied a basic Lissajous vectorscope, but the Phase 3.7 report's statement that vectorscope work was complete was premature. This phase adds all five projection modes supplied by Prism's `src/renderer/visualizers/Vectorscope.ts` and `vectorscopeGrids.ts`: Lissajous, polar unipolar/bipolar, and linear unipolar/bipolar. The layer also exposes Prism zoom, grid, native three-band traces, and low/mid/high colors. `native/src/vectorscope.cpp` and the N-API exports in `native/src/main.cpp` supply full-band and split-band point buffers. Preview and export feed both buffers when a visible layer needs multiband display. The same Prism Canvas painter renders editor stills and MP4 frames. Project version 1 remains compatible with older vectorscope files through default values.

Optional signed full-band and low/mid/high correlation bars are drawn over the meter from the latest 1024 native point pairs. They use normalized L/R cross-correlation; silent or one-sided pairs read 0. This app-owned indicator uses a shorter window than Prism's existing VU correlation display and is not claimed to be identical to MiniMeters. Each vectorscope layer has independent projection, zoom, color, band, grid, correlation, position, and size settings.

## Commands, performance, and limits

Commands run: fixture generators at 48, 44.1, and 96 kHz; `node phase2/build.cjs`; strict TypeScript over composition/editor/export with pinned Prism declarations; `node --test phase2/test/project.test.cjs phase1/test/pcm-reader.test.cjs phase3/test/vectorscope-correlation.test.cjs`; Phase 3.8 Electron smoke; `node phase3/test/vectorscope-regressions.cjs`; `node phase3/test/run-all-meters.cjs`; `python phase3/test/compare-vectorscope-frame.py` for four frames; `python phase3/test/compare-all-meters-frame.py` for three frames; `python phase3/test/verify-export.py` for 720p, 1080p, and all-eight exports; a cancelled `node phase2/export.cjs` job; syntax and diff checks.

The fresh two-scope 1080p export took **9.95 s**, including **8.75 s** in render/PNG transfer and **0.24 s** of encoder backpressure; peak Electron main-process RSS was **133,332,992 bytes**. RSS excludes renderer and FFmpeg memory. This is a local observation, not a performance guarantee.

Correlation is a 1024-sample instantaneous display and reads 0 for silence or one-sided audio, where phase is undefined. The native three-band filters have crossover/transient behavior; a brief transition can spread energy across bands. MP4 uses H.264 CRF 20, so thin high-frequency traces can lose some pixel fidelity even when geometry agrees. Long-song preview still decodes from the start and may be slow. MiniMeters-specific RGB and scaled modes, plus other rows marked as gaps in the [parity matrix](meter-parity.md), are outside this Prism-based Phase 3.8 gate.

All eight Prism meter categories now satisfy the Phase 3 editor/export gate. Next recommended phase: Phase 4 music-video composition, only after user approval.
