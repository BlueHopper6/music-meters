# MusicMeters macOS package

This folder is a MusicMeters application package for macOS (`arm64` Apple Silicon or `x64` Intel, matching `arch` in `BUILD-PROVENANCE.json`). Open `MusicMeters.app` (or run `MusicMeters.app/Contents/MacOS/MusicMeters`) from this folder to start the editor. Keep `MusicMeters.app` together with the license notices, `BUILD-PROVENANCE.json`, and `SOURCE-ARCHIVE.json` in this package folder.

The bundled runtime requires macOS 13 or later. This is a runtime minimum, not a claim that every macOS version has been tested. See the release notes for the tested OS and architecture of your exact download.

Install the FFmpeg command-line tools separately (`ffmpeg` and `ffprobe`) before importing media or exporting video. On macOS, MusicMeters checks `MUSICMETERS_FFMPEG_PATH` / `MUSICMETERS_FFPROBE_PATH` (when set), entries on `PATH`, and standard package locations (`/opt/homebrew/bin`, `/usr/local/bin`, and `/opt/local/bin`, such as `brew install ffmpeg`). Verify with `ffmpeg -version` and `ffprobe -version` in Terminal. Those two command-line executables are **not** bundled. Electron includes its own `libffmpeg.dylib` inside `Electron Framework.framework`, covered by the Chromium notices in this package. The application uses the external FFmpeg tools to decode audio and encode H.264/AAC MP4 or MKV. AAC output is lossy. The package does not upload songs or render in the cloud.

Import a WAV, FLAC, or MP3 file, select a template, adjust layers at a song timestamp, add artwork and text, and choose **Export…** to select MP4/AAC, MKV with lossless FLAC audio, a lossless RGB/float PCM master, or eligible source-audio copy. Video can be imported as a layer, with independent soundtrack levels and meter input selection. Use **Play** to preview with audio before exporting. Output defaults to 1080p/30. Choose a fresh output filename; existing files are not overwritten. Keep saved project JSON next to its `.assets` folder. Choose Copy on import to keep original-quality media with the project when saving, or Link to keep the source at its original location. If moving a project breaks a media link, use **Relink…** and save again. Templates and preferences live in `~/Library/Application Support/music-visualizer` for this macOS user account.
