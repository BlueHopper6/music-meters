# Third-party components

- **Prism**, pinned at `49721802252b115d169e353c98b27408daa5e2b7`, by its upstream contributors. License: GPL-3.0-only. This package contains Prism native analysis code and bundled Canvas painters. MusicMeters `phase2/build.cjs` injects offline frame methods and a VU frame clock into the painters when bundling, without changing the archived upstream files. See `PRISM-LICENSE.txt` and `LICENSE-NOTICES.md`. The exact Prism source is included in the paired MusicMeters source archive; upstream reference: https://github.com/Boof2015/prism/tree/49721802252b115d169e353c98b27408daa5e2b7
- **node-addon-api** 8.6.0, used to compile the Prism native addon. License: MIT. Its installed package source is in the paired source archive at `third_party/node-addon-api/`. See `NODE-ADDON-API-LICENSE.md`. Upstream reference: https://github.com/nodejs/node-addon-api/tree/v8.6.0
- **Prism native decoder and resampler dependencies**: the compiled native addon includes dr_libs and r8brain-free-src from Prism's `native/vendor/`. Their pinned revisions and roles are in `PRISM-REFERENCE_DEPENDENCIES.md`; their notices are in `PRISM-THIRD_PARTY_NOTICES.md`, `DR_LIBS-LICENSE.txt`, and `R8BRAIN-LICENSE.txt`. Their exact vendored source is in the paired source archive.
- **Electron** 45.1.0 runtime, installed from the separately locked runtime dependency. Electron's license and Chromium third-party notices are supplied in the package root as `LICENSE` and `LICENSES.chromium.html`. The copied Electron runtime includes `ffmpeg.dll`; its notice is in `LICENSES.chromium.html`.
- **FFmpeg and FFprobe command-line tools** are separately installed system prerequisites. This package does not include `ffmpeg.exe` or `ffprobe.exe`. Their applicable licenses depend on the user's installed build and configuration.

**MusicMeters application code** is GPL-3.0-only in the Prism-based distribution. See `MUSICMETERS-LICENSE.txt` and `LICENSE-NOTICES.md`. A release binary's `SOURCE-ARCHIVE.json` identifies its paired complete source archive. The separately owned logo and icons are excluded from the GPL grant; see `LICENSE-NOTICES.md` before redistributing.
