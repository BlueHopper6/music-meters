# MusicMeters Windows portable package

This folder is a portable MusicMeters build for Windows x64. Run `MusicMeters.exe` from this folder to open the editor. Keep the whole folder together. No installer is required.

Install the FFmpeg command-line tools separately and put both `ffmpeg.exe` and `ffprobe.exe` on `PATH` before starting the app. Verify with `ffmpeg -version` and `ffprobe -version` in a new terminal. Those two executables are **not** bundled. Electron includes its own `ffmpeg.dll`, covered by the Chromium notices in this folder. The application uses the external FFmpeg tools to decode audio and encode H.264/AAC MP4. AAC output is lossy. The package does not upload songs or render in the cloud.

Import a WAV, FLAC, or MP3 file, select a template, adjust layers at a song timestamp, add artwork and text, and choose **Export…** to select MP4/AAC or MKV/source-audio copy. Use **Play** to preview with audio before exporting. Output defaults to 1080p/30. Choose a fresh output filename; existing files are not overwritten. Keep saved project JSON next to its `.assets` folder. If moving a project breaks a media link, use **Relink…** and save again. Templates and preferences live in Electron user data for this Windows account.
